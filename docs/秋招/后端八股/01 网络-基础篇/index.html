基础

这里的网络基本上只指TCP/IP网络模型。tcp/ip网络模型分为四层：

  • 应用层（application layer），传输单位为消息/报文（message）
  • 传输层（transport layer），传输单位为段（segment）
  • 网络层（internet layer），传输单位为包（packet）
  • 网络接口层（link layer），传输单位为帧（frame）

注意之前的“七层网络模型”是OSI参考模型，更偏向用于理解网络抽象概念。

应用层

最上一层，在操作系统的用户态。其它三层都在内核态。

负责为用户提供功能，http、ftp、telnet、dns、smtp等都在这一层。不关注数据具体如何传输。

传输层

应用层的数据包会传给传输层。这一层包含两个传输协议：TCP和UDP。

UDP较简单，只负责发送数据包，不保证抵达。TCP保证数据包到达，有流量控制、超时重传、拥塞控制等功能。

MSS为TCP最大报文段长度；数据包大小超过MSS时就需要分块。TCP中，每个分块称为一个TCP段。每个段前面会添加tcp头。

一台机器可能有多个应用都在接受网络包，为了区分就需要端口；传输层的报文中会携带端口号，接收方可以根据端口号识别出报文发给哪个应用。

网络层

实际传输层不负责数据的传输，只是传输到应用的媒介，实际传输功能在网络层实现。

网络层的协议为IP协议。IP协议会将传输层的报文作为数据部分，再加上IP头组装为IP报文，如果超过MTU再次进行分片。

网络层负责区分设备。设备用IP地址编号。ipv4地址共32位，分为4段，每段8位。为了简化寻找设备的过程，IP地址由网络号（识别子网）和主机号组成。例如10.1.122.0/24，24代表255.255.255.0，为子网掩码；10.1.122.0为IP地址。将子网掩码和IP地址按位与，得到网络号；将子网掩码取反，和IP地址按位与，得到主机号。

某一个网段/子网中，第一、最后指的是这个网段中第一和最后的可用IP。子网中，首个地址和最后一个地址有特殊用途：第一个地址用于代表整个子网，第二个地址用于广播（发送给广播地址的消息会发给子网下的所有机器），这两个地址不能分配给某台特定的设备。

除了寻址（确认机器身份、例如起终点）外，IP还负责路由。

网络接口层

网络接口层会在IP报文之前增加MAC头并封装为数据帧、发送。封装数据帧指添加帧头、帧尾；帧头包含MAC头。

这一步关注的地址变为了MAC地址。IP地址是可变的，但MAC地址是不变的。在以太网（连接设备、通讯的技术，例如网线是以太网的组成部分）中，判断网络包目的等方法和ip不同，识别MAC地址。可以用ARP协议获取MAC地址。

这一层负责为网络层提供链路级别的传输服务。
