# 169. 多数元素

用投票算法；设置一个候选人和出现的数量，等于候选人+1，否则-1。  

原理：具体证明比较复杂，大概理解一下。令序列长度n=2k。如果某个数字是多数元素，则至少有k个。那么去掉一个n=2m且多数元素出现m次（或小于m）的情况，对答案没有影响。

# 31. 下一个排列

找到从后往前递增的序列，再找到这之前的第一个元素，称为k。显然，k应该和是递减（即从前往后递增）序列中最小的、比k大的元素互换。互换后显然序列仍然递减。将递减序列逆序得到答案。

cpp的逆序：``reverse(nums.begin(), nums.end())``.  
python可以通过切片逆序。切片的语法为``start:end:step``，正序时默认从头到尾，逆序时默认从尾到头。注意-x在start/end代表倒数第x个元素，所以对于整个数组逆序的情况，需要一些特殊处理。

# 287. 寻找重复数

等同于寻找链表中的环。  

注意数组是n + 1长度，所以nums[nums[i]]不会越界。

以[1, 2, 3, 3]为例，对应链表为：

0->1->2->3->3->3...

可以看出链表的开头就是**要求的值**而不是**下标**。此外，从0/nums[0]开始只代表在链表开头增加一个元素与否，不影响实现。

寻找环的起点采用floyd算法。快慢指针需要**从同一个起点出发**，直到相遇；相遇后慢指针不变，快指针回到**链表开头第一个元素**，再次相遇的位置即为开头元素。直接返回得到答案。

再次推导一下floyd算法：

设开头的距离为a，入口距离相遇位置为b，相遇距离入口（环）位置为c。则有$a + 2b + c = 2(a + b)$，可以得到$a = c$。
