Loss

1. MAE​

公式：mean(∣ypred−ytrue∣)mean(|y_{pred} - y_{true}|)mean(∣ypred​−ytrue​∣)

注意pytorch中，如果要 keepdim 参数，必须设置 dim 参数。

对于0维 pytorch.Tensor ，可以直接用 float() 、 bool() 等做类型转换。要转换向量内的数据类型，可以用 x.float() 等。

注意 mean 无法对整数类型使用。

代码：

y_true = y_true.float()
y_pred = y_pred.float()
return float(torch.mean(torch.abs(y_true - y_pred)))

2. RMSE && MSE​

MSE为均方误差的缩写。

MSE公式：mean((ytrue−ypred)2)mean((y_{true} - y_{pred})^2)mean((ytrue​−ypred​)2) RMSE公式：$$

MSE可导，但有对异常值敏感、单位与原数据不一致等问题。 RMSE在MSE的结果上开平方，可以让单位、数量级与原数据一致。RMSE会比MAE大。

MSE代码：

return float(torch.mean(torch.pow(y_true - y_pred, 2)))

RMSE代码：

return float(torch.sqrt(torch.mean(torch.pow(y_true - y_pred, 2))))

3. CE​

注意，H(P,Q)H(P,Q)H(P,Q) 中，P为真实分布，Q为预测分布。

公式：sum(−P⋅log(Q))sum(-P \cdot log(Q))sum(−P⋅log(Q))

其中 PPP 为真实分布， QQQ 为预测分布。（这里记混的话可以想想独热编码）

注意这里是只有一个样本的情况，如果有多个样本，最终的loss为每个样本交叉熵的均值。

return torch.sum(-P * torch.log(Q + epsilon))

没给epsilon的话可以用1e-15代替。

交叉熵的缺点是对类别不平衡敏感。

4. BCE​

输入不再是两个概率分布，而变成了一组样本的标签+预测概率；相当于每个0维向量都代表一个样本。只需要从给出的概率推断出完整的概率分布，然后就是交叉熵公式。

return torch.mean(- y_true * torch.log(y_pred + epsilon) - (1 - y_true) * torch.log(1 - y_pred + epsilon))
