# CL-bench

论文：CL-bench: A Benchmark for Context Learning    
arxiv：[https://arxiv.org/abs/2602.03587](https://arxiv.org/abs/2602.03587)

---

summary：造了一个关于context learning的bench，衡量模型从上下文学习task-specific knowledge的能力，sota模型只有17.2%。结论为现在的model都不擅长从上下文中学习，而是倾向于使用预训练中已经获得了的知识。sota模型的通过率也很低。  

失败原因：
1. 直接无视上下文中的语境
2. 长文本推理不足：上下文过长，模型无法处理复杂的推理逻辑链
3. 输出未遵循指令

其它结论：
1. 归纳推理远难于演绎推理（差6pt）
2. 对于除gpt外的大量模型，增加推理时间可以提高解决率
3. 随token增加，所有模型都一致退化
4. 同一个领域内，知识呈现方式也有影响。模型更擅长处理结构化程度更高的内容

未来的研究方向：
1. 上下文感知训练：使用预训练未知数据训练
2. 课程学习：从简单任务过渡到复杂任务  
3. 自动化生成高质量评分准则，为模型提供细粒度信号
4. 探索新架构
